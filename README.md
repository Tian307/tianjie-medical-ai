# 田洁医疗 AI 作品站 · 项目仓库

这个仓库存放田洁个人医疗 AI 作品站的静态发布文件。目前根目录页面与 [个人主页仓库](https://github.com/Tian307/Tian307.github.io)相同；两个仓库是独立副本，更新其中一个不会自动同步另一个。

## 页面展示

- 查房记录整理：文本结构化和人工复核流程演示
- 评测报告平台：字段映射、规则对齐与 Bad Case 分析流程演示
- 实习到岗助手：排班与到岗确认的交互原型，位于 `demos/intern-duty-assistant/`
- PDA 口述记录结构化助手：护理任务解析与安全校验概念演示

## 本地查看

在仓库根目录运行：

```bash
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000/`。页面由 `index.html`、`styles.css`、`app.js`、`assets/` 和 `demos/` 组成，无需构建步骤。

## 说明

这是作品展示与交互原型。部分结果由样例数据或浏览器端规则模拟，不表示已经接入真实模型或医院系统。医疗相关输出需要专业人员复核，不用于临床决策。若将两个仓库作为镜像使用，发布后需分别检查内容是否一致。
